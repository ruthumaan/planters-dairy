# Planter's Dairy

An AI-powered plantation management system for data-driven plantation decisions, soil analysis, recommendations, and intelligent reminders.

## Status
🚧 Early development — architecture and foundation.

## Repository Structure
- `data/` — raw and processed datasets.
- `notebooks/` — exploration and ML experiments.
- `src/` — reusable application and ML code.
- `app/` — future frontend/backend application.
- `models/` — trained model artifacts and metadata.
- `tests/` — automated tests.
- `docs/` — architecture, ML, soil, and decision documentation.
- `config/` — project configuration.

## Development Philosophy
This is being built as both a practical AI/ML system and a learning project. Important assumptions, experiments, results, and design decisions will be documented as the project evolves.
